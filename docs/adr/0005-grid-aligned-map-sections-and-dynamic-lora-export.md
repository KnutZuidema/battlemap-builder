# Grid-aligned 16×16 map sections and dynamic LoRA export

Curated Maps persist an explicit integer Grid Configuration (`cell_size_px`, `offset_x`, `offset_y` normalized to `[0, cell_size_px)`) and must span at least `16×16` full Grid Cells on their Ground layer. Instead of writing letterboxed `<id>_lora1024.png` and `<id>_lora1024.txt` files to disk—which distorted spatial scale across maps of different grid dimensions and baked `#0b0f17` padding bars into training data—curation partitions the map's full-grid lattice into evenly spaced `16×16` Grid Cell Map Sections (`kx = ceil(Cols / 16)`, `ky = ceil(Rows / 16)`) and caches a vision-generated Physical Description per Map Section in `manifest.json`. Both `ReferenceProvider` few-shot conditioning and LoRA dataset ZIP export (`{theme}/{id}_c{col}_r{row}_lora1024.{png,txt}`) dynamically crop and Lanczos3-resample these exact `16×16` Map Sections on demand, guaranteeing a uniform `64px = 1 Grid Cell` (`5ft`) scale with zero padding bars or redundant disk artifacts.
